# Security

Beacon Workshop is a static browser app. Progress is stored only in this browser's `localStorage` (`beacon-workshop.save.v1`, `beacon-workshop.backup.v1`). There is no login, API key, server or telemetry.

## Reporting a problem
Open a GitHub issue for ordinary bugs. For something sensitive (for example a way to run injected content or read another site's data), use GitHub's private vulnerability reporting on the repository if it is enabled, or contact the owner through the GitHub profile before posting details.

Please do not post secrets, tokens, personal data or your save file in a public issue. Describe the steps and the affected screen instead.
